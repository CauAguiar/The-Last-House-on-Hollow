## Sobre o Jogo

**The Last House on Hollow** é um jogo 2D de terror psicológico e puzzle com estilo em pixel art. Na pele de Charlie, um garoto fantasiado para o Halloween, o jogador se vê preso em uma misteriosa e antiga mansão no final da Rua Hollow. O que começa como uma busca por doces rapidamente se transforma em uma luta pela sobrevivência e pela libertação de uma família amaldiçoada.

O jogo foca em exploração, resolução de enigmas e uma narrativa ambiental profunda, onde o jogador deve desvendar a trágica história da família Craven para encontrar uma saída.

## Contexto do Projeto

Este jogo está sendo desenvolvido como um projeto para uma disciplina acadêmica. O objetivo é aplicar conceitos de game design, narrativa, arte e programação na criação de uma experiência de jogo coesa e imersiva.

## Status Atual

O projeto encontra-se na fase inicial de **desenvolvimento e prototipagem**. As tarefas atuais incluem:
* Configuração do ambiente de desenvolvimento na Unity.
* Implementação das mecânicas básicas do jogador (movimentação, interação).
* Criação dos primeiros assets visuais para o cenário principal.
