# The Last House on Hollow

Uma experiência de terror gótico em pixel art focada em narrativa, exploração e resolução de quebra-cabeças.

## Sobre o Projeto

The Last House on Hollow não é apenas um jogo sobre escapar de uma casa assombrada; é uma jornada sobre luto, memória e as consequências de tentar alterar a ordem natural das coisas.

O jogador assume o papel de Charlie, um jovem que busca abrigo em uma mansão vitoriana durante uma tempestade na noite de Halloween. Ao entrar, ele se vê aprisionado por forças sobrenaturais ligadas a um ritual antigo realizado pelo patriarca da família, Tim Craven.

Para escapar, o jogador deve investigar os cômodos da mansão, reunir as páginas do diário da família e resolver os mistérios que prendem os espíritos de Tim, sua esposa Sara e suas filhas, Dora e Ester, a uma eternidade de sofrimento.

## Funcionalidades Principais

* **Narrativa Ambiental:** A história é contada através do cenário, itens e fragmentos de diários espalhados pela casa.
* **Sistema de Puzzles:** Desafios de lógica que envolvem manipulação de objetos, interpretação de poemas e sequências musicais.
* **Estética Retro:** Visual em Pixel Art detalhado com efeitos de pós-processamento (VHS/CRT) para emular a atmosfera de terror clássico.
* **Sistema de Inventário e Interação:** Mecânicas de coleta, inspeção e combinação de itens para desbloquear novas áreas.

## Controles

* **WASD / Setas:** Movimentação do personagem.
* **Shift:** Correr.
* **E / Botão Esquerdo do Mouse:** Interagir com objetos e avançar diálogos.
* **I:** Abrir/Fechar Inventário.
* **J:** Abrir/Fechar Diário (Leitura de documentos).
* **ESC:** Pausar o jogo.

## Instalação e Desenvolvimento

Este projeto foi desenvolvido utilizando a Unity Engine. Para executar o código-fonte localmente:

1.  Certifique-se de ter a versão da Unity (2022.3 LTS ou superior recomendada) instalada.
2.  Clone este repositório:
    `git clone https://github.com/seu-usuario/the-last-house-on-hollow.git`
3.  Abra o Unity Hub e adicione a pasta do projeto clonado.
4.  Abra o projeto. A cena inicial para execução é a "Initialization" (ou "MenuPrincipal").
